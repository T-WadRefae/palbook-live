Present Perfect Continuous

for / since / How long — Real-Life Situations

Level 4 — Applied Practice

Name: ______________Date: ______________
1
Definition · التعريف

نستخدم المضارع التام المستمر مع for/since لنصف أمورًا بدأت في الماضي وما زالت مستمرّة الآن — خاصّةً بعد تغيُّر أو حدث (منذ انتقلنا، منذ بدأ العام).We describe situations that began in the past and are still going on — often since a change.

have / has been + V-ing + for / since
2
Key Facts · حقائق أساسية
  • for + مدة (for two weeks) · since + نقطة بداية أو حدث (since we moved).for + a period; since + a starting point or event.
  • للسؤال عن المدّة: How long have you been …ing?Ask about duration: How long have you been …ing?
  • النفي: haven't / hasn't been + V-ing (I haven't been sleeping well).Negative: haven't/hasn't been + V-ing.
  • نصف به كيف تسير الأمور منذ تغيُّر (since they moved to the city).It describes how things have been going since a change.
for + periodsince + point / event
for two weekssince we moved
for a long timesince last summer
for a year nowsince the term began
3
Steps · خطوات النجاح

مدّة بالأرقام أو الطول؟ → for. نقطة بداية أو حدث؟ → since. الصيغة have/has been + V-ing.A length of time → for. A starting point/event → since. Form: have/has been + V-ing.

since + حدث
We have been living here since we moved from the village.
for + مدة
She has been studying hard for three weeks.
نفي
I haven't been feeling well for a few days.
4
Summary · الخلاصة
✦ تذكّر/ي دائمًا · Remember
have/has been + V-ing + for (مدة) / since (بداية) ← مستمرٌّ حتى الآن.
