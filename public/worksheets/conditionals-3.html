الماضي والندم — Third Conditional

Type 3 — Third Conditional

Name: ______________Date: ______________
1
Definition · التعريف

الشرطية الثالثة لموقف خيالي في الماضي لم يحدث — غالبًا للندم أو تخيّل نتيجة مختلفة.The third conditional is for an unreal past that did not happen — often regret.

If + had + V3 , would have + V3
2
Key Facts · حقائق أساسية
  • جزء If: had + تصريف ثالث (past perfect).If-clause: had + past participle (past perfect).
  • النتيجة: would have + تصريف ثالث.Result: would have + past participle.
  • نستخدمها للندم أو لنتيجة مختلفة لو تغيّر الماضي.Used for regret or a different past result.
If-clause (had + V3)Main clause (would have + V3)
If I had studied,I would have passed.
If we had left early,we wouldn't have missed the bus.
If she had called,I would have helped.
3
Steps · خطوات النجاح

جزء If: had + V3؛ النتيجة: would have + V3 — كل شيء في الماضي.If-clause: had + V3; result: would have + V3 — all in the past.

ندم
If I had woken up early, I would have caught the bus.
نتيجة مختلفة
If it had rained, the plants would have grown.
ندم
If you had asked, I would have helped you.
4
Summary · الخلاصة
✦ تذكّر/ي دائمًا · Remember
Third = If + had + V3 , would have + V3 ← ماضٍ خيالي / ندم.

Let's Practice!
1
Recognize · تعرّف

Choose the correct form.اختر/ي الصيغة الصحيحة.

  1. If I had studied, I ____ the exam. ( would pass / would have passed )
  2. If we ____ early, we wouldn't have missed the bus. ( left / had left )
  3. She would have helped if you ____ her. ( called / had called )
  4. If they had known, they ____. ( would come / would have come )
2
Multiple Choice · اختيار من متعدد

Choose the correct answer.اختر/ي الإجابة الصحيحة.

  1. If I had seen you, I ____ hello. a) would have saidb) would sayc) said
  2. If he ____ harder, he would have won. a) had trainedb) trainedc) trains
  3. We would have arrived on time if the car ____ down. a) hadn't brokenb) didn't breakc) doesn't break
3
Fill in · إكمال الفراغ

Use had + V3 in the if-clause and would have + V3 in the result.استخدم/ي had + V3 في الشرط و would have + V3 في النتيجة.

  1. If I __________ (know), I __________ (tell) you.
  2. If they __________ (leave) earlier, they __________ (arrive) on time.
  3. If she __________ (study), she __________ (pass).
4
Match · توصيل

Match each if-clause with its result — write the letter.صِل/ي جملة الشرط بنتيجتها — اكتب/ي الحرف.

1) If I had saved money,____
2) If you had asked,____
3) If it had rained,____
a) I would have helped.
b) the plants would have grown.
c) I would have bought a bike.
