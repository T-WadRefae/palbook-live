Type 0 — Zero Conditional

Name: ______________Date: ______________
1
Definition · التعريف

الشرطية الصفرية للحقائق العامة والعلمية التي تحدث دائمًا (نتيجة مؤكدة).The zero conditional is for general truths & facts that are always true.

If + present simple , present simple
2
Key Facts · حقائق أساسية
  • كلا الجزأين مضارع بسيط.Both clauses use the present simple.
  • النتيجة مؤكدة دائمًا (حقيقة، وليست احتمالًا).The result is always true — a fact, not a possibility.
  • يمكن استبدال If بـ When (نفس المعنى).You can replace "If" with "When" — same meaning.
If-clauseMain clause
If you heat ice,it melts.
If it rains,the ground gets wet.
If you mix blue and yellow,you get green.
3
Steps · خطوات النجاح

استخدم/ي المضارع البسيط في الجزأين، والنتيجة حقيقة دائمة.Use the present simple in both parts; the result is always true.

حقيقة علمية
If you heat water to 100°C, it boils.
طبيعة
Plants die if they don't get water.
يومي
If the sun sets, it gets dark.
4
Summary · الخلاصة
✦ تذكّر/ي دائمًا · Remember
Zero = If + present simple , present simple ← حقيقة دائمة.
