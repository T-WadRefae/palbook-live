المستقبل الممكن — First Conditional

Type 1 — First Conditional

Name: ______________Date: ______________
1
Definition · التعريف

الشرطية الأولى لموقف واقعي ممكن الحدوث في المستقبل.The first conditional is for a real, possible situation in the future.

If + present simple , will + verb
2
Key Facts · حقائق أساسية
  • جزء If: مضارع بسيط (ليس will).The if-clause uses the present simple (not will).
  • النتيجة: will + فعل مجرد.The result uses will + base verb.
  • للوعود والتحذيرات والخطط الواقعية.Used for promises, warnings and real plans.
If-clause (present)Main clause (will)
If it rains tomorrow,we will stay home.
If you study,you will pass.
If I see him,I will tell him.
3
Steps · خطوات النجاح

جزء If مضارع بسيط، والنتيجة will — لا نضع will بعد If.If-clause = present simple; result = will. Never put "will" after "if".

تحذير
If you run, you will fall.
خطة
If the weather is nice, we will go to Jaffa.
وعد
If you help me, I will help you.
4
Summary · الخلاصة
✦ تذكّر/ي دائمًا · Remember
First = If + present simple , will + verb ← مستقبل ممكن.

Let's Practice!
1
Recognize · تعرّف

Choose the correct verb.اختر/ي الفعل الصحيح.

  1. If it rains tomorrow, we ____ home. ( stay / will stay )
  2. If you ____ hard, you will pass. ( study / will study )
  3. I will call you if I ____ time. ( have / will have )
  4. If she comes, I ____ her. ( tell / will tell )
2
Multiple Choice · اختيار من متعدد

Choose the correct answer.اختر/ي الإجابة الصحيحة.

  1. If you heat the water, it ____ boil. a) willb) isc) does
  2. We will play outside if it ____ sunny. a) isb) will bec) was
  3. If I ____ my homework, I will watch TV. a) finishb) will finishc) finished
3
Fill in · إكمال الفراغ

Use the present simple in the if-clause and "will" in the result.استخدم/ي المضارع في جملة الشرط و will في النتيجة.

  1. If it __________ (rain), we __________ (stay) home.
  2. If you __________ (help) me, I __________ (be) grateful.
  3. If they __________ (win), they __________ (celebrate).

Match · توصيل

1) If you study hard,____
2) If it is cold,____
3) If we leave now,____
a) we will catch the bus.
b) you will pass.
c) I will wear a coat.
