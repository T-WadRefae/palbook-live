الشاذّة و (not) as … as — Irregular & Equality

Level 3 — Irregular & as…as

Name: ______________Date: ______________
1
Definition · التعريف

بعض الصفات والظروف شاذّة: good/well → better → best، bad/badly → worse → worst. ونستخدم (not) as … as للمساواة، وتعمل مع الصفات والظروف معًا.Some adjectives/adverbs are irregular; use (not) as … as for equality, with both.

good/well → better → best  |  (not) as + adj/adv + as
2
Key Facts · حقائق أساسية
  • good (صفة) و well (ظرف) → better → the best.good (adj) & well (adv) → better → the best.
  • bad/badly → worse → worst · far → farther → farthest.bad/badly → worse → worst; far → farther → farthest.
  • as + صفة/ظرف + as = تساوٍ (as fast as) · not as … as = أقل.as … as = equal; not as … as = less than.
  • better / best تصلح للصفة good وللظرف well معًا.better/best work for both good and well.
WordComparativeSuperlative
good / wellbetterthe best
bad / badlyworsethe worst
farfartherthe farthest
3
Steps · خطوات النجاح

good/well؟ → better / best. bad؟ → worse / worst. تساوٍ؟ → (not) as … as.good/well → better/best. bad → worse/worst. Equality → (not) as … as.

well→better
She plays football better than me.
not as…as
Fuad doesn't feel as sick as Yasser.
as…as
Please run as fast as you can.
4
Summary · الخلاصة
✦ تذكّر/ي دائمًا · Remember
good/well → better → best · bad → worse → worst · (not) as … as للمساواة.
