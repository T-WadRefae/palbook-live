"If I were the president…" 🤔 "If it rains, I'll stay home." "If water reaches 100°C, it boils." Every time we use if to talk about conditions and results, we are using a conditional sentence. There are three main types — each for a different reality.

2 Learning Outcomes · Conditionals Types 0, 1 & 2

By the end of this lesson, students will be able to:

  • ✅ Use Zero Conditional (Type 0) for scientific facts and general truths.
  • ✅ Use First Conditional (Type 1) for real and likely future situations.
  • ✅ Use Second Conditional (Type 2) for imaginary or unlikely present/future situations.
  • ✅ Correctly position the if-clause and apply the right verb forms.
  • ✅ Distinguish between the three types based on context and meaning.

4 Teach · Three Types of Conditionals

Structure, meaning and examples for each type.

TypeMeaningIf-clauseMain clause
Zero (0)General truth / scientific factIf + Present SimplePresent Simple
First (1)Real / likely future possibilityIf + Present Simplewill + base verb
Second (2)Imaginary / unlikely / hypotheticalIf + Past Simplewould + base verb

Examples:

Type 0: If you heat water to 100°C, it boils. (Always true.)
Type 1: If it rains tomorrow, I will stay home. (Likely — might really happen.)
Type 2: If I were a bird, I would fly to Jerusalem. (Imaginary — I am not a bird.)

Key notes:

  • 🔵 In Type 2, use were (not was) for all subjects: If I/he/she were …
  • 🟢 The if-clause can come first or second: I will help if you ask me.
  • 🟡 With unless = if … not: Unless you study, you won't pass.
