# مجلد أوراق العمل — دفتر T. Wad Refae

هذا المجلد (`worksheets/`) هو **مكان تخزين كل أوراق العمل** في هذا المستودع.

## قاعدة التخزين

- **أي ورقة عمل جديدة نعملها → تُخزَّن هنا داخل `worksheets/`** (ملف HTML و/أو PDF لكل ورقة).
- **جذر المستودع (`shop`) يبقى نظيفًا** — لا نضع أي ملفات مباشرة في الجذر، فقط هذا المجلد. (فارغ حاليًا لمحتوى قادم.)

## قاعدة المخرجات

- **المخرجات تُسلَّم دائمًا كملف PDF** — أي ورقة عمل جاهزة تُصدَّر PDF (صفحات A4 قياسية 210×297mm) وتُعطى بهذه الصيغة.

## المحتوى الحالي

| الملف | الوصف |
|---|---|
| `Worksheet design system·MD` | نظام التصميم الثابت لأوراق العمل (الألوان، الخطوط، البنية، البرومبت الجاهز) |
| `present-simple-worksheet.pdf` | ورقة عمل Present Simple (نموذج مرجعي أصلي) |
| `present-simple-1.pdf` / `.html` | Present Simple — المستوى ١ (تأسيسي: العادات والروتين) |
| `present-simple-2.pdf` / `.html` | Present Simple — المستوى ٢ (الحقائق الثابتة وأفعال الحالة) |
| `present-simple-3.pdf` / `.html` | Present Simple — المستوى ٣ (الجداول والمواعيد الثابتة) |
| `present-continuous-1.pdf` / `.html` | Present Continuous — المستوى ١ (أساسي) |
| `present-continuous-2.pdf` / `.html` | Present Continuous — المستوى ٢ (متوسّط) |
| `present-continuous-3.pdf` / `.html` | Present Continuous — المستوى ٣ (متقدّم) |

> لكل ورقة ملف `.pdf` (المخرجات) وملف `.html` (المصدر، للتعديل أو النشر كصفحة ويب).

## اصطلاح التسمية المقترح

- ورقة بمستوى واحد: `<الموضوع>-worksheet.<الامتداد>` — مثال: `reported-speech-worksheet.pdf`
- عند تعدّد المستويات (ورقة لكل صف): `<الموضوع>-1.pdf` للأسهل ثم `-2.pdf` للأصعب — مثال: `present-continuous-1/2/3.pdf`

> مرجع التصميم الكامل لأي ورقة جديدة موجود في ملف نظام التصميم أعلاه.
